# Feature Plan

Candidate features include brand, model year, mileage, horsepower, engine details, fuel type, transmission, and vehicle condition when available.

Derived features may include car age and carefully chosen transformations after the dataset has been inspected. Based on the current baseline, the next iteration should emphasize age-adjusted price signals, mileage-to-age ratios, and a stronger treatment of brand-level effects while retaining interpretability.
