# Project Scope

This project will estimate the selling price of a used car from available vehicle features.

The work will cover data preparation, exploratory analysis, feature engineering, regression modeling, and evaluation. The current scope includes validating the strongest baseline model, documenting the observed metrics, and preparing the next feature-improvement cycle around the best-performing linear regression approach. The next milestone is to confirm whether a small set of engineering features can reduce validation error while preserving interpretability.
